# Installation UI

`frontend/installation-ui`

## What it is

A React app built on top of DIGIT UI Core (its own README describes it, like `micro-ui`, as a "workbench UI"). It serves the installation planning, execution, and review journeys — Project Manager plan setup and vendor assignment, Field Technician IC Report submission, and Installation Reviewer approval — described in [LLDs → Installation](../LLDs/installation/README.md).
