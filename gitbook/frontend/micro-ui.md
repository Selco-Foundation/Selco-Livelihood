# Micro UI

`frontend/micro-ui`

## What it is

The shared DIGIT UI Core module framework that `installation-ui` and platform-standard admin/workbench screens are built from. Its README describes it as a "workbench UI" React app built on top of DIGIT UI Core, and notes it is used to manage master data (MDMS v2) and localization data across DIGIT services.
