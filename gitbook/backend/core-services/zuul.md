# Zuul Gateway

`backend/core-services/zuul`

## What it does

The API gateway fronting the backend services — the standard role of Zuul in a DIGIT-derived platform, routing external requests to the appropriate backend microservice.

## Documentation note

This service's repository folder contains no source or README — only a `bin/` directory. This page's description is limited to Zuul's well-known role as an API gateway; nothing here is grounded in Livelihood-specific configuration, because no such documentation exists in this repository.
